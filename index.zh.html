實質發現

查證並非形式作業，它實際改動了資料。

三個國家的序列整體位移一年。在原始工作表中，瑞士、葡萄牙與瑞典的 Eurostat 非常規移民查獲人次序列被位移一年：Eurostat 公布之 Y+1 年數值被置於 Y 年。真正的 2010 年數值付之闕如，而 2022 年欄位實際上放的是 2023 年數字。39 筆數值已全部替換為年度對齊之 Eurostat 資料。

值得一提的後果：原始變項說明書警告瑞典查獲人次序列在 2013 年（72,835）與 2014 年（1,445）之間出現斷點。該斷點正是位移所造成的假象；在真實的 Eurostat 資料中，斷點落在 2014 與 2015 年之間。佐證已存檔為涵蓋 2010–2023 年之 Eurostat API 原始回應.

另有三處更正——臺灣的逾期停留欄位混用兩種不相容的國內統計；義大利的無證移民序列缺漏四年且混用兩種方法；兩份原始工作表因採用不同發布機構而在人口數上不一致。全部 50 筆更正均逐項載明並附佐證。

每個數字都是連結

在每個國家頁面上，Panel 資料表格的每個數字都可點選。

點選任何數值——或其旁的等級標記——即可進入該筆數字的佐證頁：包含來源、產生該數值的查詢網址、核對對象、若有更正則載明更正內容，以及支持該數值的全部存檔檔案。此類佐證頁共 156 個，每個國家的每個變項各一，並各附 PDF 摘錄，使這些數字除網頁外亦存在於可引用的固定文件中。

批次統計來源亦同。世界銀行、Eurostat、OECD 與 UN DESA 的序列，除原始 API 回應外，另有各發布機構自身資料集頁面的 PDF 與截圖鏡像，皆擷取於取得當日。

如何使用本存檔

供編輯與審查委員參考。

  • 每份檔案都有穩定的相對網址可供下載。沒有任何內容藏在腳本、查詢字串或外部服務之後。
  • API 資料以原始回應形式存檔。世界銀行、Eurostat、OECD 與 UN DESA 於 2026-08-17 回傳的 JSON 與試算表內容原封保存於 evidence/api/，並附上產生各該回應的查詢網址。
  • 網頁來源以三種方式存檔（在可行的情況下）：原始 HTML、PDF 鏡像，以及整頁 PNG 截圖，全部擷取於 2026-08-17。
  • 完整性可供驗證。本存檔每一份檔案的 SHA-256 校驗碼均已公布。
  • 查證過程可重複執行。所使用的每一支腳本均收錄於 scripts/。
