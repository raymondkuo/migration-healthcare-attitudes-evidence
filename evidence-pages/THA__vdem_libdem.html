Definition note. V-Dem liberal democracy index (v2x_libdem): "To what extent is the ideal of liberal democracy achieved?", interval scale from 0 (low) to 1 (high); it combines the electoral democracy index (v2x_polyarchy) with the liberal component index (v2x_liberal) as .25*polyarchy^1.585 + .25*liberal + .5*polyarchy^1.585*liberal. An estimate from V-Dem's Bayesian measurement model of expert ratings, published to three decimals with a 68% interval (v2x_libdem_codelow/codehigh, in data/vdem_source_comparison.csv). Definition, interval and annual aggregation: V-Dem Codebook v16, PDF pages 48, 32 and 42 (evidence/api/vdem_codebook_v16_retrieved_2026-10-26.pdf).
How this was confirmed. Read directly from the archived V-Dem v16 data file (evidence/api/vdem_v16_vdemdata_vdem_retrieved_2026-10-26.RData: data/vdem.RData of the V-Dem Institute's R package vdemdata 16.0, release commit f4dd269 of 2026-03-17, git blob hash as GitHub records it), decoded with R (scripts/92_decode_vdem.R); Our World in Data's copy of V-Dem v16 (evidence/api/owid_liberal-democracy-index_retrieved_2026-10-26.csv) gives the same value at V-Dem's three decimals. Retrieved 2026-10-26.
